# E-Commerce Delivery Analytics

## Project Overview
This project analyzes e-commerce order data to understand delivery performance, revenue trends, customer satisfaction, and refund requests using Python and data visualization libraries.

## Objectives
- Analyze order value and revenue across e-commerce platforms.
- Evaluate delivery delays and delivery performance.
- Understand customer feedback and service ratings.
- Explore refund request patterns.
- Generate insights to support business decision-making.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset Information
The dataset includes the following columns:
- Order ID
- Customer ID
- Platform
- Order Date & Time
- Delivery Time (Minutes)
- Product Category
- Order Value (INR)
- Customer Feedback
- Service Rating
- Delivery Delay
- Refund Requested

## Key Analysis
- Order distribution by platform.
- Revenue analysis by product category and platform.
- Delivery delay analysis across platforms.
- Relationship between order value and delivery time.
- Customer service rating and refund analysis.

## Project Files
- `Ecommerce_Delivery_Analytics.ipynb` — Jupyter Notebook containing data cleaning, exploratory data analysis, and visualizations.
- `Ecommerce_Delivery_Analytics.csv` — Dataset used for the analysis.

## How to Run
1. Download or clone this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Upload the CSV dataset if required.
4. Run the cells sequentially to reproduce the analysis.

## Skills Demonstrated
Python programming, data cleaning, exploratory data analysis (EDA), data manipulation, data visualization, and business analytics.
